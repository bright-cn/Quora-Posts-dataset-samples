此 **Quora 帖子数据集样本**包含 **1,218 条记录**，并使用 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `url` | Quora 帖子的唯一 URL。 |
| `post_id` | Quora 上每篇帖子的唯一标识符。 |
| `author_name` | 创建帖子的作者姓名。 |
| `title` | Quora 帖子的标题，用于概括其内容。 |
| `post_date` | 帖子发布的日期和时间。 |
| `originally_answered` | 表示该帖子最初是否用于回答特定问题。 |
| `over_all_answers` | 帖子收到的回答总数。 |
| `post_text` | Quora 帖子的主要内容或正文文本。 |
| `pictures_urls` | 帖子中包含的所有图片的 URL。 |
| `videos_urls` | 帖子中包含的所有视频的 URL。 |
| `extarnal_urls` | 帖子中引用的外部 URL。 |
| `upvotes` | 帖子收到的点赞数，反映其受欢迎程度。 |
| `shares` | 用户分享该帖子的次数。 |
| `views` | 帖子的总浏览量。 |
| `top_comments` | 帖子中用户发布的精选评论。 |
| `author_content_views` | 作者所创作全部内容的总浏览量。 |
| `author_active_spaces` | 作者参与的活跃 Quora Space（社区）数量。 |
| `author_joined_date` | 作者加入 Quora 的日期。 |
| `author_about` | 作者的简短介绍或个人简介。 |
| `author_education` | 有关作者教育背景的信息。 |
| `header` | 帖子中提供的其他标题信息。 |


## 使用场景

### 1. 情感分析
分析 Quora 帖子的情感倾向，以了解公众对各种话题的看法，用于市场研究或社会研究。

### 2. 主题建模
利用主题建模识别 Quora 上的热门主题和讨论，帮助内容创作者和营销人员了解受众兴趣。

### 3. 作者影响力分析
通过分析点赞数和分享次数等互动指标来评估 Quora 作者的影响力，从而识别关键意见领袖。
